# 项目概述
这是一个 Unity 2D 无限防守模式+ 肉鸽（Roguelike / Roguelite）元素游戏。

## 游戏核心玩法
- 游戏类型为无限防守模式，每局游戏内会有无限波次怪物进攻player，每波会随机产生某一范围内的enemy，当Player击败所有enemy或者该波到达30S之后，自动进入下一波。
- 该游戏为竖屏游戏，在游戏局内模式Player位于屏幕下侧进行防守，enemy从屏幕上方随机生成，enemy直线向下接近Player，然后进行攻击。
- buff选择：每波结束后获得随机 Buff选择，每次会提供三种buff供选择，提升Player的属性或技能等级，具有高度重复可玩性。
- buff系统：buff分为两种类型，一种buff类型用于提升Player的四维基础属性，一种buff用于提升Player的技能效果。
- skill系统：skill分为射击技能，闪电技能，落雷技能，火系技能，水系技能，冰霜箭矢技能，恢复技能
- 局内获得的buff效果为临时效果，游戏局外的技能效果提升和Player思维属性效果为永久性效果
- 局内的每次获得的buff为同一类型的buff，要么都是提升思维属性的buff，要么都是提升技能效果的buff，每四次buff选择的机制中，前三次为四维属性buff，最后一次为技能效果buff，分别从四维属性buff池和技能效果buff池中随机选择
- 局内每击杀一个怪物，获得一定经验，为Player设定经验池数据，当获得的经验达到可升级时，为Player提供buff选择
- 局内每隔一定时间会随机产生Boss，Boss的属性随波次进行提升
- 设定特殊技能池，Boss可随机获得特殊技能池中的技能
- 特殊技能池：冲锋技能，护盾技能，分裂技能，召唤技能，远程攻击技能，为附近enemy增益的技能
- Player的技能池：
  1.射击技能 - 基础单发子弹单弹道，拥有以下buff点：buff - 双弹道，buff - 三弹道， buff - 四弹道， buff - 每次双发子弹， buff - 每次三发子弹， buff - 子弹弹射一次， buff - 子弹弹射两次， buff - 子弹击中目标分裂一次， buff - 子弹击中目标分裂两次，buff - 子弹穿透增益（增益： 1， ，3）
  2. 闪电技能 - 从Player处发射一条闪电射向敌人，拥有以下buff ：buff - 一次发射两条（三条/四条）闪电、 buff - 闪电会连接两个（三个/四个/五个）目标、buff - 闪电会在最后位置爆炸造成伤害、buff - 闪电会造成短暂麻痹效果 
  3.落雷技能 - 随机生成一道落雷，攻击范围内的enemy，拥有以下buff：buff - 落雷数量增加（2/3/4/5）、buff - 落雷伤害范围增大（增大30%/50%/80%/100%130%）、buff - 落雷对攻击范围内所有敌人造成麻痹禁锢效果 、buff - 落雷禁锢时间增加（20%/50%）、buff - 落雷范围爆炸圈可短暂持续，持续时间增加（30%， 50%， 100%）
  4.火雨技能 - 随机降落一小片火雨，对enemy造成范围伤害，以下buff： buff - 火雨范围扩大（30%/50%/80%/100%）、buff - 火雨持续时间增益（30%/50%/80%/100%）、buff - 传递性，杀死当前敌人时，会继续传递到附近的第（2/3）个敌人 
  5.水浪技能 - 生成一道水浪，造成伤害的时，产生减速效果，拥有buff - 水浪数量增加，产生第（2/3）条水浪、buff - 减速效果增益，持续时间2秒（30%/50%/80）、buff - 减速时长增益30%/50%/80%/100%）、buff - 水浪范围扩大（体积增大30%/50%）、
  6. 冰系技能 - 发射一个冰霜箭矢，对箭矢轨迹上的所有敌人造成伤害，并且造成冰冻0.5s效果,拥有以下buff：buff - 增加冰霜箭矢的发射弹道（2/3）、buff - 增加冰霜箭矢的发射数量（2/3）、buff - 增加冰霜箭矢的冰冻时间（30%/50%/100%）、buff - 增大冰霜箭矢的体积，造成更大范围的冰冻效果、 buff - 箭矢在飞行距离减半，但是会在飞行终点产生爆炸，冻结大范围enemy及长时间冰冻效果（2s/3s/4s）buff - 如果冰霜箭矢爆炸，爆炸范围增大（30%/50%/80%）   
  7.恢复技能 - 恢复Player或者墙被攻击后的血量以及最大血量，拥有以下buff：buff - 每秒恢复1%的血量、buff - 提高最大血量（30%/50%/80%100%）、buff - 每隔一分钟恢复10%血量、buff - 每隔3分钟，提升血量的最高点10%、buff - 一次性恢复慢血量 （一次性buff）  
  8. 通用增益buff： buff - 射速增益（增益：10%， 20%，30%...可叠加），buff - 基础伤害增益（增益：10%， 20%，30%...可叠加）， buff - 爆击概率增益（增益：10%， 20%，30%...可叠加），buff - 爆击伤害增益（增益：10%， 20%，30%...可叠加）， buff - 冷却时间增益（增益：10%， 20%，30%...可叠加， 但有最低冷却时间限制），通用buff可以进行不断进行叠加
- 游戏奖励机制：当每次游戏结束后，根据当局的游戏时长及玩家等级玩家可获得奖励，奖励包括金币，水晶，技能升级卡，属性升级卡，通用升级卡
- Player成长机制：玩家的四维属性、技能效果，装备等级可升级，提升玩家的战斗力，玩家通过技能升级卡和通用升级卡，可以为某个选择选择技能效果，通过属性升级卡和通用升级卡，可以提升Player的基础四维属性，这种属性提升是永久性的
- 背包系统：背包中可以存储获得的所有奖励
- enemy系统：Enemy分为普通enemy和Boss，普通enemy只有基础的属性，没有特殊技能，Boss可以获得特殊技能
- 装备系统：Player具有基础的装备，装备通过游戏奖励掉落，在局外，Player可以通过装备合并完成升级，提升玩家的四维属性
- 商店系统：通过广告激励，金币，水晶，固定奖励获得技能升级卡，通用升级卡，属性升级卡，装备等
- 签到系统：通过七日签到系统，玩家获得金币，水晶，技能升级卡，通用升级卡，属性升级卡，装备等奖励
- 抽奖系统：玩家通过抽奖可以获得金币，水晶，技能升级卡，通用升级卡，属性升级卡，装备等奖励
- 游戏时长奖励： 玩家通过当天在线游戏时长可以获得金币，水晶，技能升级卡，通用升级卡，属性升级卡，装备等奖励
- 体力机制：Player具有体力限制，每次进入游戏消耗体力，体力消耗完毕需要等待五分钟恢复一点体力，或者通过广告恢复体力
- 排行榜：用于展示当前玩家的游戏局内通关波次的排行榜

## 技术栈
- 引擎：Unity 6000.3.6f1 LTS（推荐，稳定且长期支持）
- 渲染：URP（通用渲染管线）以获得最佳 2D 渲染性能和后处理效果
- 语言：C#（.NET Standard 2.1）
- 版本管理：使用程序集定义（Assembly Definition）组织代码
- 外部依赖：尽量不引入第三方插件，优先使用 Unity 原生功能

## 命名规范
- 脚本文件名与类名一致，使用 PascalCase。
- UI 元素命名格式：类型_名称（如 `Btn_Start`、`Txt_Score`、`Img_Health`）。
- 场景对象命名格式：功能描述（如 `SkillObject_Bat`、`Enemy_Spawner`）。
- Prefab 命名格式：类型_名称.prefab（如 `Skill_Bullet.prefab`、`Enemy_Bat_01.prefab`）。
- ScriptableObject 资产命名格式：数据类别_名称.asset（如 `SkillBuffSo.asset` 、 `BaseBuffSO.asset`）。

## 目录结构规则
- 脚本按系统功能模块分类存放于 `Assets/Scripts/`：
  - `Core/`：游戏核心系统（GameManager、WaveManager、UpgradeManager 等）
  - `Player/`：Player相关（Player、PlayerDataSO、Player_Health、PlayerShootState 等）
  - `Enemies/`：敌人相关（Enemy、EnemyDataSO、EnemySpawner 等）
  - `Bullets/`：子弹/投射物相关（Bullet类）
  - `Roguelike/`：肉鸽系统（UpgradeManager、BuffDataSO、SkillBuff、 BaseBuff、Buff 效果实现）
  - `UI/`：UI 相关（UIManager、各界面面板）
  - `Managers/`：全局管理器（AudioManager、PoolManager、ResourceManager）
  - `Data/`：ScriptableObject 数据定义
  - `Utils/`：工具类（ExtensionMethods、MathHelper 等）
  - `Pool/`：对象池系统
- 资源文件按类别存放于 `Assets/Art/`、`Assets/Prefabs/`、`Assets/Audio/` 等目录。

## 编译与性能
- 使用程序集定义（Assembly Definition）文件组织代码，减少不必要的编译范围。
- 大世界地图使用 Tilemap 系统构建，搭配 Grid 和 TilemapRenderer。
- 遵循数据驱动设计原则：所有塔和敌人的数值通过 ScriptableObject 配置，便于后期调优和扩展。
- 优先使用对象池管理频繁生成的对象（子弹、特效、敌人实例）。
