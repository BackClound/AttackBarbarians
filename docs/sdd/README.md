## SDD 标准结构

每份 SDD 统一包含：

1. 文档元信息（版本、关联 PRD、负责人）
2. 系统概述与边界
3. 需求追溯（US / FR / AC）
4. 架构与核心类
5. 数据模型与配置
6. 流程 / 状态机
7. 事件与接口
8. **实现状态分析**（已完成 / 部分 / 缺失）
9. 已知问题与技术债
10. 测试要点
