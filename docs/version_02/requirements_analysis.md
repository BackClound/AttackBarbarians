## 2. 用户故事（核心）

```
作为玩家，我希望在竖屏单手操作中自动战斗，
以便专注选择 Buff  build 应对越来越强的波次。

作为玩家，我希望每局 build 不同（Roguelike），
以便重复游玩不枯燥。

作为玩家，我希望局外永久成长，
以便长期投入有回报。
```

## 3. 约束条件

- Unity 6000.3 LTS + URP 2D
- 尽量不引入第三方插件
- 遵循 `.cursor/rules/` 全套规范
- 保持现有场景/Prefab 引用不失效（迁移期）

## 4. 验收标准（Release MVP）

1. 完整一局：MainMenu → Playing → 3+ 波 → 升级选择 → GameOver → 结算
2. 射击技能 + 至少 2 种额外技能可释放
3. 属性/技能 Buff 四循环机制正确
4. 天赋/装备局外加成在局内生效
5. 无战斗帧明显 GC spike（Profiler 验证）
6. 所有核心数值来自 SO 配置
