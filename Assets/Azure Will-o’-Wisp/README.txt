------------------------------------
📌 Requirements
------------------------------------
- Unity 2021.3 LTS or newer
- Spine-Unity Runtime (NOT included)

Download Spine-Unity Runtime for free:
https://github.com/EsotericSoftware/spine-runtimes

------------------------------------
📌 How to Use
------------------------------------
1. Import Spine-Unity Runtime into your Unity project.
2. Import this package:
   Unity → Assets → Import Package → Custom Package...
3. Drag the prefab (Hero.prefab / WolfBeast.prefab) into your Scene.
4. Press Play to see the idle animation running.
5. Switch animations from the SkeletonAnimation component 
   in the Inspector (e.g., Idle, Attack, Skill, Stun, Hit ...).
